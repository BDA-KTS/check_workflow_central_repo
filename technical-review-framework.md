# Method Technical review Framework

This framework evaluates [Methods Hub](https://methodshub.gesis.org/) method repositories across three dimensions: **reusability and attribution**, **reporting transparency**, and **computational reproducibility**. Each dimension categorized as fully, partially or not satisfying the [Methods Hub guidelines](https://github.com/GESIS-Methods-Hub/guidelines).


| Dimension | Fully satisfied | Partially satisfied | Not satisfied |
|---|---|---|---|
| **Reusability and attribution** | ![Reusability](https://img.shields.io/badge/Reusability-fully%20reusable-green) <br> Valid open licence and `CITATION.CFF` file | ![Reusability](https://img.shields.io/badge/Reusability-partially%20reusable-yellow) <br> Multiple licences leading to ambiguity of applicable terms | ![Reusability](https://img.shields.io/badge/Reusability-not%20reusable-orange) <br> Missing valid open licence or `CITATION.cff` file |
| **Transparency** | ![Transparency](https://img.shields.io/badge/Transparency-fully%20documented-green) <br> All mandatory files found, README as per Methods Hub template | ![Transparency](https://img.shields.io/badge/Transparency-partially%20documented-yellow) <br> Duplicate files, README duplicate sections or formatting issues | ![Transparency](https://img.shields.io/badge/Transparency-insufficiently%20documented-orange) <br> One or more mandatory files missing, one or more required README sections missing |
| **Computational reproducibility** | ![Reproducibility](https://img.shields.io/badge/Reproducibility-single%20click%20reproducible-green) <br> `repo2docker` builds the environment successfully, and the programming language version is specified | ![Reproducibility](https://img.shields.io/badge/Reproducibility-partially%20reproducible-yellow) <br> `repo2docker` builds successfully, but the programming language version is not specified | ![Reproducibility](https://img.shields.io/badge/Reproducibility-not%20reproducible-orange) <br> `repo2docker` fails to build the environment |
